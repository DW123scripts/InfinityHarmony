# More Info
If you don't know much about installing 3rd party apps, it is recommended that you review the FAQ:

**Q) Why not on Google Play Store?**  
A) To keep the project accessible and cost-effective, I’ve chosen to host it independently. While the code was developed with AI assistance, it is designed with security in mind.

**Q) Will it work on all phones?**
A) No, it will not work on all phones; it will only run on Android, which includes Pixel, Samsung and almost any phone that isn't an iPhone.

### Please read through.
I have only run this phone on a Pixel 7. Since it is not from Google Play, it may not install without bypassing some security.

## Here is how to install
1. Open the link at the top of this README
2. Press **HarmonyStudio.apk**. It will download and then, if there is a notification at the top, open it and/or if it opens the download page, continue to step 4.
3. Open the download page. (On Chrome, select the 3 dots in the top right and select downloads.
4. Select the APK you just downloaded.
5. It should show "Open with Package installer" or something like that, select "just once".
6. Then select "Install".
7. It may or may not ask if you want it scanned. If it asks, select more and then install without scanning, then enter your pin.
8. If something else happens, always just press install anyway, usually under "more."
